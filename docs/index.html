מחברות GPU (קולאב + קגל)

לחיצה אחת פותחת את שתי המחברות בלשוניות חדשות. הדף הזה נשאר פתוח, אפשר להמשיך ליצור בפוליניישנז בזמן שהן עולות.

הפרומפט נבנה אוטומטית מ-LOCK + ACTION + סצנה + SET. קגל רץ ברקע ואפשר להישאר בדף. קולאב לא ניתן להפעלה אוטומטית (ראה למטה).

קולאב בלבד קגל בלבד
  1. קולאב: Runtime ← Run all, הדבק את הפרומפט בתא 2.
  2. קגל: Accelerator ← GPU, Internet ← On, Save & Run All.
  3. אורך נעול: 81 פריימים (5.06 שניות).

יצירה

וידאו בפוליניישנז עולה פולן בתשלום, ויתרת התשלום כרגע 0 (היתרה שמוצגת למעלה חינמית ועובדת לתמונות בלבד). לוידאו חינמי השתמש בכפתורי קולאב/קגל.
